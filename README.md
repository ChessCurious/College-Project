# Random Joke Generator

A simple Python project that prints a random joke every time you run it.  
Perfect for beginners learning how to use lists, functions, and randomness in Python.

---

##Features
- Generates a random joke from a predefined list
- Lightweight and beginner-friendly
- No external dependencies
